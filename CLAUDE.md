## Branches

PRs target `staging` (`gh pr create --base staging`), not `main`. `staging` is a permanent integration branch that is merged into `main` later. Branch feature work from `ocyris/staging`.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on the fork 0cyris/comfyui-openrouter_node (not upstream gabe-init). See `docs/agents/issue-tracker.md`.

### Triage labels

Default labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
